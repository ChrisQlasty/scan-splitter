# 📷 Scan Splitter

Splits scanned pages that contain several photos (1–10 per scan) into separate, straightened photo files.

## Installation (one time only)

### Windows
1. Go to **https://www.python.org/downloads/** and click the big yellow **Download Python** button.
2. Open the downloaded file. **Tick the box "Add python.exe to PATH"** at the bottom, then click **Install Now**.
3. Download this app folder (green **Code** button → **Download ZIP**) and unzip it, e.g. to your Desktop.

### Mac
1. Go to **https://www.python.org/downloads/** and click **Download Python**. Open the file and click through the installer.
2. Download this app folder (green **Code** button → **Download ZIP**) and unzip it, e.g. to your Desktop.

## Using the app

1. Open the app folder and double‑click:
   - Windows: **Start Scan Splitter (Windows).bat**
   - Mac: **Start Scan Splitter (Mac).command**
     *(First time on Mac: right‑click the file → **Open** → **Open**, because macOS warns about downloaded files.)*
2. The first start takes 1–2 minutes (it installs what it needs). Your web browser then opens the app.
3. Click **Choose folder with scans** and pick the folder with your scanned pages.
4. Wait while the photos are found. Use **⟲ / ⟳** under each photo to turn it upright. Untick **keep** for anything you don't want.
5. Click **Save photos**. The photos are saved in a new folder called **split** inside your scans folder, which opens automatically.

To quit, close the black terminal window.

## Tips for best results
- Leave a small gap (≈1 cm) between photos on the scanner glass.
- Keep the scanner lid closed (or use a plain sheet behind the photos).
- Supported files: JPG, PNG, TIFF, BMP.
